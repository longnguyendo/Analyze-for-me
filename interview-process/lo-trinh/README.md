# Lộ trình phỏng vấn SE (~1.5 YOE)

Lộ trình chuẩn bị dựa trên **NeetCode** + **Cracking the Coding Interview (CTCI)**, bổ sung **scalability**, **reliability**, **CS fundamentals**, và **networking**.

Mức mục tiêu: Software Engineer với ~1.5 năm kinh nghiệm (vượt junior thuần, chưa cần depth của Senior).

## Nền tảng chung (học trước / song song)

Xem [nen-tang-chung.md](./nen-tang-chung.md) — NeetCode roadmap, CTCI chapters, checklist scalability / reliability / networking.

## Cách dùng

1. Học **nền tảng chung** 2–3 tuần trước (hoặc song song tuần 1–4).
2. Chọn 1–2 công ty ưu tiên → follow lộ trình riêng.
3. Mỗi tuần: coding (NeetCode) + CS/system notes + mock interview.
4. Ghi journal sau mỗi mock / vòng thật vào `interview-process/`.
