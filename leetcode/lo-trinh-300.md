# Lộ trình 300 bài LeetCode

Mục tiêu: cover đủ pattern phỏng vấn (NeetCode-style) với **300 bài**. Hint từng bài nằm trong folder [`hints/`](./hints/).

## Cách dùng

1. Làm theo thứ tự topic (không nhảy lung tung).
2. Mỗi bài: tự nghĩ ≥15' → mở hint → code → ghi pattern notes.
3. Easy ~15', Medium ~25–35', Hard không bắt buộc timed lúc đầu.
4. Mỗi chủ nhật: ôn lại bài đã sai trong tuần.

## Timeline gợi ý

| Cường độ | Thời gian hoàn thành 300 |
|----------|---------------------------|
| 1–2 bài/ngày | ~5–8 tháng |
| 3–4 bài/ngày | ~3–4 tháng |
| Full grind (5–8/ngày) | ~6–10 tuần |

Ưu tiên phỏng vấn SE: hoàn thành **Topic 1–14** trước (~220 bài), rồi bổ sung Hard / Design.
