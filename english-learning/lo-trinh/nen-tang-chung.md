# Nền tảng chung (dùng cho IELTS + TOEIC)

## 1. Đánh giá đầu vào (tuần 0)

| Test | Làm gì |
|------|--------|
| TOEIC diagnostic | 1 đề ETS full → biết band Listening/Reading |
| IELTS diagnostic | Cambridge practice test (hoặc IELTS Progress Check) |
| Vocab level | Oxford 3000 / Anki placement |

Ghi kết quả vào `english-learning/level/baseline.md` (tự tạo khi có số liệu).

## 2. Vocabulary hệ thống

| Nguồn | Mục đích |
|-------|----------|
| Oxford 3000 / 5000 | Core daily |
| Academic Word List (AWL) | IELTS Writing/Reading |
| TOEIC frequent words (part 1–7 themes) | Office, travel, finance, HR |
| Collocations | make/do/take + noun (quan trọng Writing) |

**Ritme:** 15–20 từ mới/ngày + ôn Anki (spaced repetition). Target active vocab ≥ 6000–8000 trước khi thi IELTS 7.0 / TOEIC 900.

## 3. Grammar must-have

- Tenses (đặc biệt present perfect vs past)
- Conditionals 0–3
- Relative clauses, noun clauses
- Passive (Academic Writing hay dùng)
- Articles & prepositions (lỗi trừ điểm nhiều)
- Subject–verb agreement, parallelism

Nguồn: English Grammar in Use (Murphy) — làm bài, không chỉ đọc.

## 4. Listening foundation

- Hàng ngày: 20–30' input (BBC Learning English / VOA / podcast 1.0–1.2x)
- Kỹ thuật: **dictation ngắn** (1–2 phút) 3 lần/tuần
- Shadowing: nghe–nói bám nhịp 10'/ngày (giúp Speaking IELTS + TOEIC Part 2/3/4)

## 5. Reading foundation

- Skimming (ý chính) / Scanning (số liệu, tên)
- Paraphrase recognition (IELTS & TOEIC đều bẫy paraphrase)
- Đọc đều: 1 article/ngày (The Guardian / National Geographic / BBC) — ghi 5 paraphrase

## 6. Ritme tuần mẫu (song song 2 mục tiêu)

| Ngày | Focus |
|------|--------|
| Mon | Vocab + Grammar drills |
| Tue | Listening (TOEIC Part 3–4 hoặc IELTS Section 3–4) |
| Wed | Reading (1 passage IELTS hoặc TOEIC Part 7) |
| Thu | Writing Task 1 **hoặc** Speaking cue card |
| Fri | Full skill practice (1 kỹ năng timed) |
| Sat | Mini mock (2 kỹ năng) |
| Sun | Review lỗi + Anki catch-up |

## 7. Công cụ

- Anki / Quizlet
- YouGlish (phát âm trong ngữ cảnh)
- Grammarly / LanguageTool (Writing nháp — không phụ thuộc hoàn toàn)
- Cambridge / ETS official materials (ưu tiên đề thật)
