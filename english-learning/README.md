# Phân tích trình độ và quá trình học tiếng Anh

Theo dõi trình độ, mục tiêu, phương pháp học và tiến độ tiếng Anh theo thời gian.

## Gợi ý tổ chức

- `level/` — đánh giá trình độ hiện tại (CEFR, IELTS, …)
- `study-log/` — nhật ký học tập
- `resources/` — tài liệu và nguồn học
- `goals/` — mục tiêu ngắn hạn / dài hạn
